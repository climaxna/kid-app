# 로컬 클립 작업

- 기존 `pipeline.py`와 설정 JSON을 재사용한다. 영상마다 새 편집 스크립트를 만들지 않는다.
- 후보 검토에는 해당 작업의 `review-brief.md`를 먼저 읽고, 필요한 구간만 추가 확인한다.
- 제목·시간·상황 자막 변경은 `edit.json`에 반영하고 `pipeline.py render`로 실행한다.
- 원본과 모델별 대사 캐시를 유지한다. 스타일 수정만으로 재다운로드·재인식하지 않는다.
- 키워드 기반 후보 점수는 재미를 보장하지 않는다. 자동 인식 대사를 검수 전 확정 대사로 단정하지 않는다.
- 최종 종료점은 로컬 MP4와 검사 결과다. 사용자 요청 없이 외부 업로드하지 않는다.
