# B 목소리 영상 샘플

사용자가 선택한 B 목소리(Supertonic 3 M2)로 제작한 이사야 41장 10절 샘플.
대상: 50대 이상 개신교 시청자.
방향: 십자가가 보이는 노을과 바다, 중앙의 큰 흰색 글씨와 검은 테두리, 잔잔한 피아노.

## 파일

- isaiah41-10-B-sample.mp4: 검토할 영상
- B-narration.wav: 음악 없는 전체 낭독
- cross-sunset.png: 생성 배경 원본
- cover.jpg / verse.jpg / last-verse.jpg: 영상에서 추출한 확인 화면
- QA.json: 문구·타이밍·음량·파일 검사 기록
- build_sample.py: 제작 코드

## 음악 출처

피아노 샘플: Salamander Grand Piano — Alexander Holm (CC BY 3.0).
https://github.com/Tonejs/audio/tree/master/salamander
https://creativecommons.org/licenses/by/3.0/
개별 음 샘플로 새 선율을 구성했으며 음높이·잔향·길이를 조정했습니다.

음성은 Supertonic 3의 제공 목소리 M2를 사용해 로컬 생성했습니다.
참고 녹음의 목소리를 복제하거나 외부 서비스에 업로드하지 않았습니다.
배경은 내장 image_gen으로 새로 생성했습니다. 프롬프트는 IMAGE_PROMPT.md에 있습니다.

## 검토 포인트

목소리의 발음과 쉼, 배경의 분위기, 글씨 크기, 음악과 목소리의 균형을 확인합니다.
이 샘플의 방향이 정해진 뒤 나머지 편을 제작합니다. 아직 공개 게시하지 않았습니다.
