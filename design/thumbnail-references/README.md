# 썸네일 스타일 레퍼런스

스타일 참고용 이미지. 블로그에 그대로 올리지 않는다(원작자 저작물).
AI에 스타일 참고로 첨부할 때도 "이 느낌으로, 그대로 베끼지 말고"로 쓴다.
변화를 주고 싶을 때 폴더 안에서 번호를 바꿔 가며 쓴다.

| 폴더 | 스타일 | 쓰는 글 |
|---|---|---|
| halftone | 하프톤 인쇄 사진 (원색 배경, 점 질감, 레트로 잡지) | 육아 정책, 바로답 |
| travel-poster | 빈티지 여행 포스터 (평면 도형, 촘촘한 풍경, 제한된 색) | 섬 여행 |
| photo-doodle | 사진 위 낙서 (실사 + 손그림 레터링·캐릭터) | 커넥트 제품 |
