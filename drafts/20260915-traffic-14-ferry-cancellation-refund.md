# 여객선 결항되면 환불은 어떻게 받을까 직접 취소 전 확인할 것

여객선 결항 환불은 먼저 **예약한 편이 실제 결항으로 확정됐는지** 확인하는 것부터 시작합니다. 기상악화로 선사가 취소한 경우와 여행자가 미리 취소한 경우는 처리 기준이 다를 수 있어요. 그렇다고 무조건 기다리라는 뜻은 아니며, 아직 결항이 확정되지 않았다면 개인 취소 마감과 수수료 기준도 함께 확인해야 합니다.

## 결항과 지연과 개인 취소를 구분하세요

| 현재 상태 | 먼저 할 일 | 피해야 할 판단 |
| --- | --- | --- |
| 해당 편 결항 확정 | 예약처에 결항 환불 처리 확인 | 모든 예약이 자동 취소된다고 생각하기 |
| 출항 지연 안내 | 변경 시각과 처리 조건 문의 | 지연을 결항과 같게 보기 |
| 예보만 나쁨 | 운항 상태와 개인 취소 기한 확인 | 예보만으로 무료 취소 확정하기 |
| 본인 사정으로 포기 | 취소 시점별 규정 확인 | 나중에 결항될 수 있다며 기한 놓치기 |

출발지 날씨가 좋거나 비가 조금 온다는 이유만으로 판단하지 마세요. 예약편의 운항 여부는 선사 공지와 예약처 안내로 확인해야 합니다. 같은 항구의 다른 배가 결항됐다고 내 배도 자동으로 결항인 것은 아니에요.

## 기상 결항이면 배값을 돌려받을 수 있나요

고려고속훼리 운송약관은 기상 등 선사의 책임이 아닌 사유로 출항 전에 운항할 수 없게 된 경우 운임을 돌려주는 기준을 두고 있습니다. 다만 이 조항을 모든 예약 상품의 부대비용과 여행 경비까지 전액 보상한다는 뜻으로 확대해서는 안 됩니다.

이용 선사, 구매한 상품, 운항이 중단된 시점에 따라 확인할 내용이 달라집니다. 특히 이미 일부 구간을 이용했다면 전체 왕복 금액이 아니라 미사용 구간을 구분해 처리할 수 있어요. 자신의 예약에 적용되는 약관과 취소 내역을 확인하세요.

여행자 본인이 버튼을 눌러 취소하기 전에 결항 처리 방식이 따로 있는지 문의하면 잘못된 수수료 적용을 줄이는 데 도움이 됩니다. 이미 직접 취소했다면 무조건 환불이 안 된다고 단정하지 말고 결항 확정 시점과 결제 내역을 가지고 예약처에 확인하세요.

## 예약한 곳에 이렇게 문의하면 됩니다

문의할 때는 선박 이름, 승선 날짜와 시각, 구간, 예약번호를 준비하세요. 공개 댓글에는 예약번호와 전화번호 등 개인정보를 올리지 말고 예약처의 비공개 문의 창구를 이용하는 것이 좋습니다.

“오늘 예약한 이 편이 결항 확정인지, 결항 환불로 처리되는지, 제가 별도로 취소해야 하는지”를 먼저 물어보세요. 그다음 승객 운임과 차량 운임이 모두 처리되는지, 별도 구매한 구간이 남아 있는지 확인하면 됩니다.

환불 완료 예상일은 결제 수단과 예약처 처리 방식에 따라 다를 수 있어요. 취소 접수가 됐다는 안내와 카드 승인 취소 또는 계좌 입금이 끝났다는 안내를 구분해 보세요. 모든 결제가 당일 즉시 되돌아온다고 생각하면 안 됩니다.

## 차량과 왕복편은 각각 확인하세요

| 예약 항목 | 확인할 질문 |
| --- | --- |
| 승객 운임 | 모든 승객이 결항 취소에 포함됐나요 |
| 차량 선적 | 차량 예약도 함께 취소됐나요 |
| 돌아오는 편 | 입도하지 못한 경우 복귀편은 어떻게 처리하나요 |
| 다른 선사 구간 | 별도 예약이라 따로 접수해야 하나요 |

가는 배가 결항됐다고 다른 날의 돌아오는 배나 다른 선사 표까지 자동 환불되는 것은 아닐 수 있습니다. 왕복 예약 화면에 남아 있는 구간이 없는지 확인하고, 환승 여행이면 각 구간을 나눠 점검하세요.

차량만 다른 방식으로 보내거나 승객만 항공편으로 이동하는 대안을 생각한다면 기존 예약의 취소와 새 운송 계약을 별도로 확인해야 해요. 배편 변경을 결정하기 전에 전체 비용과 인수 장소가 맞는지도 살펴보세요.

## 숙소와 기차는 배표 환불과 별도입니다

숙박이나 육지 교통편은 배표와 계약이 다릅니다. 결항 사실이 있다고 모두 같은 규정으로 무료 취소되는 것은 아니므로 각 예약의 기상악화 관련 조건을 확인하세요. 증빙이 필요하다면 선사나 예약처에 결항 확인 자료의 발급 또는 확인 방법을 문의할 수 있습니다.

숙소에 연락할 때는 결항된 편과 여행 날짜를 설명하고 적용 가능한 변경 또는 취소 조건을 물어보세요. 증빙을 보내더라도 반드시 원하는 보상이 나온다고 보장할 수는 없습니다. 안내받은 내용과 처리 결과는 기록해 두는 편이 좋습니다.

## 결항 전에는 기다릴 기한도 정해 두세요

아직 결항이 확정되지 않았는데 여행을 포기할 생각이라면 개인 취소 수수료가 바뀌는 시점을 먼저 확인하세요. “결항되겠지” 하고 기다리다가 불리한 취소 구간에 들어갈 수 있습니다. 예약처에 현재 상태와 적용 기준을 문의한 뒤 결정하는 것이 좋습니다.

여객선 결항 환불은 결항 확인, 예약처 문의, 승객과 차량 및 왕복 구간 점검, 실제 환불 확인 순서로 정리하면 됩니다. 자료는 2026년 9월 15일 확인한 [고려고속훼리 운송약관](https://www.kefship.com/m/schedule/content11.php)을 참고했으며, 실제 분쟁이나 환불 금액은 해당 계약과 적용 규정을 확인해야 합니다.
