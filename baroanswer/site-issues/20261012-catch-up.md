# 추납·임의가입 계산기 오류 보고 (2026-10-12)

대상: https://u-jeverse.com/pension/catch-up (그리고 같은 함수를 쓰는 /pension/voluntary-continue)

## 원문 대조

- 국민연금법 제92조 (연금보험료의 추후 납부): 10년 미만의 범위에서 추후 납부를 신청할 수 있고, 추후 납부 보험료의 기준소득월액은 "추후 납부를 신청한 날이 속하는 달"을 기준으로 한다. 추후 납부로 산입되는 기간의 기본연금액은 "납부한 날이 속하는 달"을 기준으로 산정한다.
- 국민연금법 제51조: 기본연금액의 B값은 가입자 개인의 전체 가입기간 평균 기준소득월액이다.
- 국민연금법 시행령 제10조 제1항: 임의가입자 기준소득월액은 지역가입자 전원의 중위수에 해당하는 금액(본인이 높게 신청 가능).
- 국민연금법 제10조(임의가입 18세 이상 60세 미만), 제13조(임의계속가입 65세까지)는 사이트 설명과 일치.
- 보험료율 2026년 9.5%, 추납 최대 119개월은 사이트와 일치.

## 사이트 오류

위치: `C:\portal\src\lib\pension.ts` `catchUpEffect` (272행 근처)

현재 식(수정 전): 늘어나는 연금 = `calculateBasicPension({...input, joinYears: joinYears + 개월/12})` 의 월 연금 − 지금의 월 연금.
- 채운 기간도 "기존 평균소득월액"으로 B값을 계산한다. 보험료 기준소득월액(`contributionBase`)은 낼 보험료에만 쓰이고 연금에는 반영되지 않았다. 100만 원으로 넣어도 350만 원으로 넣어도 늘어나는 연금이 같았다. 화면 설명("높게 잡으면 보험료도 연금도 함께 오른다")과도 맞지 않았다.
- 채운 기간에 가입연도를 이어 붙인 상수(예: 가입 2012년 시작 8년이면 2020~2022년 상수)를 쓴다. 제92조는 납부한 날이 속하는 달 기준이므로 2026년 상수 1.29를 써야 한다.

틀린 예시 한 줄: 1985년생, 2012년 가입 8년, 평균 350만 원, 기준소득월액 100만 원으로 36개월 추납하면 월 증가액 41만 8,763원(수정 후 37만 4,979원). 이미 12년 가입자가 같은 조건으로 36개월 채우면 10만 5,841원이 아니라 6만 1,583원.

## 고친 내용

- `PensionInput`에 `addedMonths`, `addedIncome`(선택) 추가. `calculateBasicPension`이 B값을 전체 가입기간 가중평균으로 계산하고, 채운 기간은 납부 연도(`CONTRIBUTION.catchUpYear` 2026)의 상수로 계산한다.
- `catchUpEffect`가 위 두 값을 넘긴다.
- 검산: 1974년생 2000년 가입 8년 평균 250만 원, 기준소득월액 100만 원 36개월 추납 → 손 계산(가중평균 B = (250만×96+100만×36)/132, 상수 1.8×96개월+1.29×36개월, 지급률 60%)으로 월 402,276원, 함수 결과와 일치.
