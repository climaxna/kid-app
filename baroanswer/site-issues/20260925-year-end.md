# 사이트 오류 보고: 연말정산 환급금 계산기 (/tax/year-end)

작성 2026-09-25 (자동 작업 baroanswer-calculator-draft). 사이트 파일은 수정하지 않았다.

> **처리 2026-09-25:** 사용자 지시로 `C:\portal` 커밋 e70cd72에서 수정, 같은 날 push·배포 확인. 내용은 portal `PROJECT_STATUS.md` 같은 날짜 항목.

## 결론

- 자녀세액공제 금액: **틀림.** 2024.12.31 개정 전의 옛 금액을 쓰고 있다.
- 신용카드 등 소득공제 기본 한도: **틀림.** 2023년 이전의 3단계 구간을 쓰고 있다.
- 신용카드 추가 한도(전통시장·대중교통): **틀림.** 항목별 100만원씩으로 계산하지만, 법은 합산 한도다.
- 이 세 가지만 확인하고 대조를 멈췄다(두 번째 오류라 오늘 글은 쓰지 않음). 의료비·교육비·기부금·보험료·연금계좌 값은 대조하지 않았다.

## 1. 자녀세액공제

### 조문 원문 (소득세법 제59조의2 제1항, law.go.kr 현행)

> 1. 1명인 경우: 연 25만원
> 2. 2명인 경우: 연 55만원
> 3. 3명 이상인 경우: 연 55만원과 2명을 초과하는 1명당 연 40만원을 합한 금액

(개정 이력에 2024.12.31, 2026.4.21 표시)

### 사이트 코드

`C:\portal\src\config\year-end-tax.ts`

```ts
export const CHILD_CREDIT = { first: 150_000, second: 200_000, thirdAndMore: 300_000 }
```

주석에 "2026년 세제개편안이 인상을 제안했으나 국회 확정 전이라 반영하지 않는다"고 적혀 있지만, 25만/55만/40만원은 이미 법률에 들어가 있다.

### 틀린 예시 (`calculateYearEndTax` 직접 호출)

| 자녀 수 | 사이트 | 법 조문 |
|---|---|---|
| 1명 | 150,000원 | 250,000원 |
| 2명 | 350,000원 | 550,000원 |
| 3명 | 650,000원 | 950,000원 |

한 줄 요약: 자녀 2명이면 세액공제가 20만원 적게 잡혀서, 사이트가 환급액을 20만원(지방세 포함 22만원) 적게 보여준다.

### 추가 확인 필요

현행 제1항 첫 문장에 "손자녀로서 13세 이상의 사람"이라는 문구가 보인다(2026.4.21 개정 표시). 대상 나이가 8세에서 13세로 바뀌었는지, 시행 시기(2026 귀속분부터인지)를 부칙으로 확인해야 한다. 사이트 주석과 안내 문구는 "8세 이상"이다.

## 2. 신용카드 등 소득공제 한도

### 조문 원문 (조세특례제한법 제126조의2)

제10항
> 제2항에 따른 신용카드등소득공제금액은 연간 250만원(해당 과세연도의 총급여액이 7천만원 이하인 경우에는 연간 300만원)을 한도로 한다. 다만, 자녀 및 손자녀 등 대통령령으로 정하는 부양가족(이하 이 항에서 "자녀등"이라 한다)이 있는 사람에 대해서는 ... 7천만원 이하인 경우: 자녀등이 1명인 경우 연간 350만원, 자녀등이 2명 이상인 경우 연간 400만원 / 제1호 외의 경우: 자녀등이 1명인 경우 연간 275만원, 자녀등이 2명 이상인 경우 연간 300만원 <개정 2025.12.23>

제11항
> 한도를 초과하는 금액과 다음 각 호의 금액의 합계액 중 작거나 같은 금액을 ... 추가한다.
> 1. 제2항제1호 및 제2호의 금액의 합계액(연간 200만원을 한도로 하되, 해당 과세연도의 총급여액이 7천만원 이하인 경우에는 같은 항 제3호의 금액을 추가로 합쳐 연간 300만원을 한도로 한다)

### 사이트 코드

`C:\portal\src\config\year-end-tax.ts` `CREDIT_CARD_DEDUCTION`

```ts
baseLimitTiers: [
  { upTo: 70_000_000, limit: 3_000_000 },
  { upTo: 120_000_000, limit: 2_500_000 },
  { upTo: Infinity, limit: 2_000_000 },
],
extraLimitPerCategory: 1_000_000,
```

`C:\portal\src\lib\year-end-tax.ts` 76~83행에서 전통시장과 대중교통에 각각 `Math.min(..., 1_000_000)`을 적용한다.

- 총급여 1억2천만원 초과를 200만원으로 제한하지만 법은 250만원이다(7천만원 초과는 한 구간).
- 자녀 수에 따른 기본 한도 상향(350만/400만, 275만/300만)이 없다. 2025.12.23 개정이라 적용 귀속연도를 부칙으로 확인한 뒤 반영해야 한다.
- 추가 한도가 항목별 100만원씩이다. 법은 전통시장과 대중교통 공제액을 합쳐 200만원, 총급여 7천만원 이하는 문화체육사용분까지 합쳐 300만원이다. 문화체육사용분(도서·공연 등 30%) 입력 칸도 없다.

### 틀린 예시

- 총급여 1억3천만원, 신용카드 6천만원: 사이트 기본 공제 2,000,000원, 법 한도 2,500,000원.
- 총급여 4,500만원, 신용카드 4천만원 + 전통시장 500만원 + 대중교통 300만원: 사이트 추가 공제는 100만원 + 100만원 = 200만원에서 멈춘다. 법은 합산 한도 300만원까지 인정된다(전통시장 200만원 + 대중교통 120만원 = 320만원 → 300만원).
