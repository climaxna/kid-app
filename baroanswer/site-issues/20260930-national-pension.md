## 원문과 맞은 것 (고치지 않음)

- 국민연금법 제51조 제1항(2026. 1. 1. 시행): 기본연금액 = (A + B) × **1천분의 1천290**, 20년 초과 1년(1개월은 1/12년)마다
  본문 금액의 1천분의 50 가산 → 사이트 상수 1.29, `1 + 0.05n/12` 일치.
- 법률 제8541호 부칙 제20조(2025. 4. 2. 개정): 2008년 1천분의 1천500 … 2025년 1천분의 1천245(해마다 0.015 감소) → `pensionConstant` 일치.
  1988~1998년 2.4(A+0.75B), 1999~2007년 1.8은 국민연금공단 '급여의 산정' 산식으로 확인.
- 제63조 제1항: 20년 이상 기본연금액, 10~20년 미만 1천분의 500 + 10년 초과 1년(1개월 1/12)마다 1천분의 50 → 지급률 일치. 제61조: 가입 10년 이상.
- 부칙 제8조: 수급연령 1953~56년생 +1 … 1969년 이후 +5 → 수급·조기 연령 표 일치.
- A값: 2025.12월~2026.11월 지급사유 발생자 3,193,511원(공단 '급여의 산정') 일치.
- 부양가족연금액(2026.1~12월분): 배우자 연 306,630원, 자녀·부모 1인당 연 204,360원 일치.
- 기준소득월액 상·하한: 보건복지부고시 제2026-31호, 2026년 7월분~2027년 6월분 하한 410천원·상한 6,590천원 → 상한 659만원 일치.
- 제88조·부칙: 2026년 보험료율 1천분의 95 → 9.5% 일치.

## 틀린 것

1. **기준소득월액 상한을 계산에 적용하지 않았다.**
   - 원문: 기준소득월액은 상한 6,590천원(고시 제2026-31호). B값은 기준소득월액의 평균(제51조 제1항 제2호).
   - 코드: `const bValue = safe(input.monthlyIncome)` — 입력값을 그대로 씀. 보험료 어림(`contributionEstimateOf`)도 같음.
   - 화면 설명은 "상한(월 659만원)이 있어 그 이상 벌어도 보험료와 연금이 더 늘지 않습니다"라고 적어 계산과 어긋났다.
   - 틀린 예: 2012년 가입·30년·월 800만원 → 계산기 월 1,839,234원 / 원문 기준(B = 659만원) 월 1,607,553원.
2. **부양가족연금 부모 나이 요건을 "60세 이상"으로만 안내했다.**
   - 원문: 제52조 제1항 제3호 "60세 이상" + 법률 제8541호 부칙 제8조(법률 제5623호 제48조 제1항 제3호의 지급연령에
     1953~1956년생 1세 … 1969년 이후 5세를 더함). 국민연금공단 부양가족연금 안내: "1953~1956년생 61세, 1957~1960년생 62세,
     1961~1964년생 63세, 1965~1968년생 64세, 1969년생 이후 65세".
   - 코드: 계산기 칸 안내 "자녀는 19세 미만, 부모는 60세 이상.", 설명 표 "60세 이상 또는 장애 2급 이상", `DEPENDENT_PENSION.note`.
   - 틀린 예: 1965년생 부모(현재 61세) → 사이트 안내상 대상 / 원문상 64세부터 대상. 금액 계산은 입력 인원수만 써서 달라지지 않는다.

3. **설명 문구가 계산 결과와 어긋났다** (법령 오류는 아님, 원문 산식으로 계산한 값과 비교).
   - "10년과 20년의 차이가 두 배가 넘습니다"(페이지·차트 설명) → 기본 예시(350만) 10년 382,785원, 20년 740,051원 = 1.93배.
   - "20년을 넘어서면 증가 속도는 느려지지만" → 제51조 단서로 20년 초과 1년마다 5%, 제63조로 10~20년도 1년마다 5%라 같은 속도.
   - "내 소득이 A값보다 … 높으면 그 반대입니다"(낸 것보다 적게 받는다고 읽힘) → 사이트 모델에서 상한 소득도 수익비 3.3배.

## 고친 내용

- `lib/pension.ts`: `cappedIncome()`로 B값과 보험료 어림을 `CONTRIBUTION.maximumBase`(659만원)에서 자름. 결과에 `incomeCapped` 추가.
- 계산기: 소득 칸 안내에 상한 표시, 상한을 넘으면 결과 설명 첫 줄에 "상한 6,590,000원으로 계산했습니다". 부모 안내 "출생연도에 따라 60~65세 이상".
- `config/pension.ts`: `DEPENDENT_PARENT_AGE` 표 추가(근거 주석), note 수정.
- 페이지: 부양가족 표 부모 요건 "60~65세 이상(부모 출생연도별)", 출생연도별 나이 문단 추가.
- 문구: 10년→20년 배수를 계산해 표시("20년은 10년의 1.9배"), 20년 뒤 증가 속도 문장, A값 설명 "높을수록 그 배수가 줄어듭니다".
- 검증: 원문 산식 직접 계산과 비교 — 2012·30년·350만 1,099,828 / 300만 1,017,671 / 659만 1,607,553 / 800만 1,607,553(예전 1,839,234) /
  15년·300만 518,319 / 2020년 가입 300만 997,542 모두 일치. 기본 예시(350만·30년) 그대로. 린트(바꾼 파일)·빌드 통과.

## 범위 밖 (이번에 고치지 않음)

- 유족연금 계산기(`config/survivor.ts`, `app/pension/survivor/page.tsx`)도 부모·조부모 유족 요건을 "60세 이상"으로만 적었다.
  부칙 제8조가 법률 제5623호 제63조 제1항 제3호·제5호 단서(유족 부모·조부모)의 지급연령도 같은 방식으로 늦춘다. 다음 점검 때 고친다.
- 기준소득월액 하한(41만원)은 계산에 넣지 않았다. 월 41만원 미만을 넣는 경우만 해당한다.
- B값은 연도별 재평가율로 현재가치 환산한 평균이라, 과거 상한을 재평가한 값은 659만원과 조금 다를 수 있다. 사이트는 현재 상한으로 어림한다.
