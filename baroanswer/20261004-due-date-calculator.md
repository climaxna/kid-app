# 출산 예정일 계산 2026 마지막 생리 시작일이 6월 1일이면 예정일은 며칠일까

<!-- info -->
테스트기에 두 줄이 뜨고 병원에 가면
제일 먼저 듣는 질문이 있어요.
**"마지막 생리 시작일이 언제예요?"**

임신 40주를 아기가 생긴 날부터
세는 줄 아는 분이 많아요.
그런데 병원은 ==생리 시작일==부터 세요.
그래서 임신 1~2주는 아직 임신 전이에요.

<!-- box: quotation_corner -->
> 출산 예정일 = 마지막 생리 시작일 + 280일 (40주)
> 2026년 6월 1일이 시작일이면 **2027년 3월 8일 월요일**
> 생리 주기가 28일이 아니면 그 차이만큼 보정해요

## 예정일은 어떻게 나오나요

이 방법을 네겔레 법칙이라고 불러요.
마지막 생리 시작일에 280일,
주로 바꾸면 40주를 더해요.
서울시민건강포털도 최초 생리일부터
280일을 임신기간으로 본다고 안내해요.

280일에는 한 가지 가정이 숨어 있어요.
생리 주기가 ==28일==이고
배란이 14일째에 일어난다는 거예요.
수정은 시작일 2주쯤 뒤라서
아기가 실제로 자란 기간은 38주쯤이에요.

주기가 다르면 그 차이를 더하거나 빼요.
이 계산기도 같은 식을 써요.

> 예정일 = 시작일 + 280일 + (내 주기 - 28일)

!!배란일을 정확히 안다면 배란일 + 266일도 같은 날짜예요.!!
6월 1일 시작이고 28일 주기라면
배란일이 6월 15일이라
266일을 더해도 3월 8일이에요.

## 달력으로 세는 요령은 하루이틀 어긋나요

병원에서 쓰는 손쉬운 요령도 있어요.
생리를 시작한 달에서 3을 빼고
날짜에는 7을 더하는 방법이에요.
빨리 가늠할 때는 편한데
달마다 길이가 달라서 날짜가 어긋나기도 해요.

| 마지막 생리 시작일 | 280일로 센 예정일 | 달력 요령 |
|---|---|---|
| 2026년 1월 15일 | 2026년 10월 22일 목 | 10월 22일 |
| 2026년 3월 10일 | 2026년 12월 15일 화 | 12월 17일 |
| 2026년 6월 1일 | 2027년 3월 8일 월 | 3월 8일 |
| 2026년 12월 25일 | 2027년 10월 1일 금 | 10월 2일 |

3월 10일에 시작했다면
==2일 차이==가 나요.
계산기는 280일을 날짜로 세서
이런 어긋남이 없어요.

## 생리 주기가 다르면 예정일이 이만큼 달라요

시작일은 2026년 6월 1일로 같고
평균 주기만 바꿔 봤어요.

| 평균 생리 주기 | 출산 예정일 |
|---|---|
| 24일 | 2027년 3월 4일 목 |
| 26일 | 2027년 3월 6일 토 |
| 28일 | 2027년 3월 8일 월 |
| 30일 | 2027년 3월 10일 수 |
| 32일 | 2027년 3월 12일 금 |
| 35일 | 2027년 3월 15일 월 |

주기가 길수록 배란이 늦어져서
예정일도 같은 만큼 밀려요.
28일에서 ***4일 멀어지면 예정일도 4일***
움직여요.

주기가 들쭉날쭉하다면
이 계산은 오차가 더 커져요.
모르겠으면 28일로 두고
병원에서 초음파로 다시 확인하세요.

## 몇 주째인지는 날짜표로 한눈에 봐요

예정일보다 자주 쓰는 건
"지금 몇 주 며칠째"예요.
시작일이 6월 1일이면
주수별 날짜는 이렇게 돼요.

| 주수 | 날짜 | 알아둘 점 |
|---|---|---|
| 4주 0일 | 2026년 6월 29일 | |
| 8주 0일 | 2026년 7월 27일 | |
| 12주 0일 | 2026년 8월 24일 | 1분기 막바지 |
| 14주 0일 | 2026년 9월 7일 | 2분기 시작 |
| 20주 0일 | 2026년 10월 19일 | |
| 28주 0일 | 2026년 12월 14일 | 3분기 시작 |
| 37주 0일 | 2027년 2월 15일 | 만삭 시작 |
| 40주 0일 | 2027년 3월 8일 | 출산 예정일 |
| 42주 0일 | 2027년 3월 22일 | |

임신 기간은 세 구간으로 나눠요.
1분기는 0~13주, 2분기는 14~27주,
3분기는 28주부터 출산까지예요.
37주부터 42주 전까지는 만삭으로 봐요.

기준일을 2026년 10월 4일로 넣으면
**17주 6일째, 2분기**예요.
이틀만 지나면 18주가 돼요.

## 예정일에 딱 맞춰 태어나는 아기는 드물어요

예정일은 어림값이에요.
정해진 날이라기보다
그 무렵이라고 보는 게 맞아요.

- 37주부터 42주 전 사이에 태어나면
  만삭으로 봐요
- 첫 출산인지 아닌지에 따라서도 달라져요
- 쌍둥이 같은 다태아는 일찍 태어나는 경우가 많아
  담당 의사가 시기를 따로 안내해요

!!예정일이 지났다고 바로 걱정할 일은 아니에요.!!
다만 진통, 양수, 태동 변화가 있으면
날짜와 상관없이 병원에 연락하세요.

## 초음파로 7일 넘게 차이 나면 초음파가 우선이에요

생리일이 기억과 다르거나
주기가 불규칙한 분도 많아요.
그래서 임신 초기 초음파로 한 번 더 맞춰요.

미국산부인과학회 기준으로
14주 전 초음파 날짜가
생리일 기준과 ==7일 넘게== 다르면
초음파 날짜로 예정일을 바꿔요.
9주 전이라면 5일을 넘을 때 바꿔요.

예를 들어 계산기가 3월 8일을 줬는데
초음파가 3월 1일 근처를 가리키면
병원 예정일이 계산기와 다를 수 있어요.
이때는 **병원 예정일이 맞는 날짜**예요.

!!계산기 날짜는 병원 가기 전 어림값으로 쓰세요.!!
산모수첩에 적힌 날짜가 기준이에요.

## 예정일 알았으면 진료비 지원부터 챙겨요

임신이 확인되면
건강보험 가입자나 피부양자는
임신·출산 진료비를 지원받아요.
소득 기준 없이 신청할 수 있어요.

| 항목 | 내용 |
|---|---|
| 지원 금액 | 임신 1회당 100만 원 |
| 다태아 | 140만 원에 더해 태아당 100만 원이 되도록 추가 (2024년 1월 1일 이후 임신) |
| 분만취약지 | 20만 원 추가 |
| 사용 기한 | 분만 예정일 또는 출산일로부터 2년 |
| 쓸 수 있는 곳 | 임산부 진료, 약제·치료재료 본인부담금과 2세 미만 영유아 의료비 |

병원에서 임신확인서를 받은 뒤
국민건강보험공단이나 정부24,
국민행복카드 발급 은행·카드사에서
신청해요.
==사용 기한이 예정일 기준==이라
예정일부터 알아두면 편해요.

## 출산 예정일 계산할 때 알아둘 점

- 생리 **시작일**을 넣어요
  끝난 날이 아니에요
- 평균 주기를 모르면 28일로 두세요
- 예정일은 40주가 되는 날이고
  만삭은 37주부터예요
- 시험관 시술이나 배란일을 아는 경우는
  병원이 따로 계산해요
- 이 계산은 날짜 안내이고
  의학적 진단이 아니에요

## 예정일은 계산기로 바로 확인해요

제가 만든 무료 계산기 사이트 **바로답**의
==출산 예정일 계산기==는
생리 시작일만 넣으면 예정일과
지금이 몇 주 며칠째인지 알려줘요.

<!-- box: quotation_postit -->
> 1단계 마지막 생리 시작일 넣기
> 2단계 평균 생리 주기 넣기 (모르면 28일)
> 3단계 기준일 넣기 (오늘 날짜)
> 결과 출산 예정일, 오늘 기준 주수와 분기, 분기별 시작일

2분기와 3분기가 시작되는 날도
달력 날짜로 같이 보여줘요.
