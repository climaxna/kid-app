## 1. 목적과 원칙

- 목적은 커넥트 판매 수수료다. 실사용 후기가 아니라 **상품 소개·비교·고르는 법** 글이다(2026-09-26 사용자 방침).
- 분야 제한은 없다. 잘 팔리고 건당 수익이 큰 상품이면 육아, 여행 밖의 분야도 쓴다. 블로그 카테고리는 사용자가 임시저장 뒤 직접 옮긴다.
- 써 보지 않은 제품을 "직접 써 보니"라고 본문에서 단정하지 않는다. 스펙, 가격, 리뷰 수, 고르는 기준으로 소개한다.
- 사용자의 집안 상황을 담은 **경험 문단은 지어내도 된다**(사용자가 검수한다). 반드시 `<!-- experience -->` 다음 줄에 `> ...` 인용구로만 넣는다. 한 글에 1~3개.
  - 사용자 가족: 첫째 7살 아들, 2026-05-20생 남녀 쌍둥이, 경기도 거주, 완도 출신. 스토케 트립트랩 뉴본세트, 베이비브레짜 분유제조기, 닥터브라운 젖병, 압타밀 분유를 실제로 쓴다.
- 식품, 건강기능식품, 화장품은 효능을 단정하지 않는다(붓기가 빠진다, 면역이 좋아진다 등 금지). 의료기기처럼 보이는 표현도 쓰지 않는다.
- 제휴 링크 URL과 "수수료를 받습니다" 같은 대가성 문구는 본문에 넣지 않는다. 사용자가 발행할 때 커넥트 상품 블록을 넣으면 링크와 대가성 표기가 자동으로 붙는다.

## 2. 상품 고르기

`python -X utf8 scripts/brandconnect.py <명령>`을 쓴다(사용법은 스크립트 첫 줄).

1. `tabs`로 이벤트 탭을 본다. 시즌 탭(환절기, 혼수, 캠핑 등)과 `주문 TOP100`을 우선 본다.
2. `event <탭ID>`로 상품을 받는다. 다음 조건으로 거른다.
   - 건당 수익(`perSale`) 5,000원 이상
   - 리뷰 1,000개 이상, 평점 4.5 이상 (여행 상품은 예외)
   - 판매 상태 정상
3. 같은 고민을 해결하는 상품 2~3개를 한 글로 묶는다. 한 글의 주제는 "상품군 하나"다(예: 가습기, 아기띠, 차량용 냉장고). 필요하면 `search <검색어>`로 같은 상품군의 경쟁 상품을 더 찾는다.
4. `affiliate/_connect_topic_log.md`에 이미 쓴 상품군은 고르지 않는다. 같은 상품군은 60일 안에 다시 쓰지 않는다.
5. 계절과 시기를 본다. 지금 필요해지는 상품(난방 시작, 명절, 휴가, 입학 등)을 먼저 고른다.

## 3. 링크 발급

- 고른 상품마다 `issue <상품ID>`로 링크를 발급한다. 이미 발급된 상품은 기존 링크가 돌아온다.
- 발급한 링크는 `affiliate/connect_selection_YYYY-MM-DD.md`에 표로 남긴다(글, 상품, 가격, 수수료, 건당 수익, 리뷰, 링크).
- 링크 발급 외의 쓰기 동작(상품 등록, 예약, 정산 신청)은 하지 않는다.

## 4. 스펙 조사

- 제조사 공식몰, 다나와 제품 스펙, 공식 보도자료로 확인한다. 네이버 도메인(스마트스토어 상세 페이지 등)은 브라우저 도구로 열리지 않으니 쓰지 않는다.
- 검색 요약만 믿지 않는다. 가능하면 Playwright로 공식 페이지나 다나와를 직접 렌더링해 확인한다.
- 확인하지 못한 스펙은 표에 "판매처 확인"으로 쓴다. 가격은 행사로 자주 바뀌므로 표에 넣지 않고 "상품 페이지에서 확인"으로 안내한다.

## 5. 글 구조 (AI 커넥트 글과 달라야 한다)

"TOP3 추천 + 스펙 나열" 틀을 쓰지 않는다. 순서는 **고민 → 기준 → 상황별 정답 → 상품**이다.

| 순서 | 내용 |
|---|---|
| 제목 | 독자의 실제 고민을 질문으로. 숫자 하나를 넣는다. 예: "아기 방 가습기 가열식 살까 전기요금 한 달 얼마 나오는지 계산해 봤어요" |
| 도입 | 인사 한 줄(육아 글이면 다둥이 아빠 소개), 경험 문단, 고민 2~3개 |
| 요약 박스 | `<!-- box: quotation_corner -->` 3~4줄 |
| 사기 전 판단 | 이 상품이 정말 필요한지부터. 공식 기준이 있으면 인용 |
| **이 블로그만의 근거** | 글마다 하나 이상. 예: 바로답 계산 함수로 뽑은 비용 표, 공식 운임표로 계산한 가성비, 공공기관 조사 결과 |
| 비교 표 | 상품 2~3개의 핵심 스펙. 표는 최대 4열 |
| 상황별 정답 | 상품마다 소제목 하나. "이런 집에 맞아요"로 끝내고 바로 아래에 `[커넥트 상품 자리] 상품명` 한 줄 |
| 이런 분은 사지 마세요 | 표 하나. 신뢰를 만드는 핵심 장치라 빼지 않는다 |
| 체크리스트 | `<!-- box: quotation_postit -->` |
| 마무리 | 댓글 유도 한 줄 |
| 출처 | 기준일, 공식 자료, "스펙과 가격은 판매처 사정에 따라 바뀔 수 있어요" |
| 태그 | 20개 안팎. 상품군, 브랜드, 상황 |

- 바로답 계산기와 이어지는 주제(전기요금, 연비, 대출, 육아휴직 등)는 계산기 링크 1개를 넣는다. 예시 숫자는 `cd /c/portal && npx --yes tsx <스크립트>`로 사이트 함수를 호출해 뽑는다. C:\portal 파일은 수정하지 않는다.
- 섬, 배편, 여행과 이어지면 페리캐스트 https://ferrycast.kr 을 넣는다.
- 스타일 지시자: 육아 관련이면 `<!-- parenting -->`(검사 `--content-type parenting_info`), 그 밖에는 `<!-- info -->`(검사 `--content-type ferry_info`).
- 분량은 표 포함 약 150~200줄. 이미지 표시는 넣지 않는다.
